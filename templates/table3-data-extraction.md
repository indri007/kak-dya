# Tabel 3 — Data Extraction Items

| Kategori | Item | Format |
|----------|------|--------|
| **Studi** | ID, Penulis, Tahun, Negara | Text |
| **Desain** | Model hewan / RCT / Non-acak / In vitro | Enum |
| **Karakteristik Sel** | Subset (CD8+, Th1, Treg, dll.) | Text |
| **Intervensi** | Dosis, Durasi, Jadwal | Numeric + Text |
| **Luaran Fungsional** | Skor klinis, sitokin, histologi | Numeric |
| **Risk of Bias** | SYRCLE / RoB 2 / ROBINS-I | Enum |
| **Catatan** | Missing data, korespondensi | Text |
