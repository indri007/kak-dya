## 📋 Tentang Proyek

Protokol **Systematic Literature Review (SLR)** ini menyelidiki keseimbangan antara sel T efektor (CD8+, Th1) dan sel T regulator (Foxp3+ Treg) pada penyakit autoimun. Protokol disusun mengikuti **PRISMA-P 2015** dan disiapkan untuk pelaporan akhir berbasis **PRISMA 2020**.

## 🎯 Tujuan

1. Mensintesis bukti preklinis dan klinis tentang rasio efektor/regulator pada penyakit autoimun.
2. Memetakan heterogenitas metodologis (model hewan, uji klinis, in vitro).
3. Mengidentifikasi gap penelitian untuk desain studi selanjutnya.

## 📊 Metodologi Ringkas

- **Database**: PubMed/MEDLINE, Scopus, Web of Science, Embase, Cochrane CENTRAL
- **Registri**: ClinicalTrials.gov, WHO ICTRP
- **Preprint**: medRxiv, bioRxiv
- **Penapisan**: 2 reviewer independen, Cohen's κ, pilot 50 record
- **Risk of Bias**: SYRCLE (hewan), RoB 2 (RCT), ROBINS-I (non-acak), domain in vitro
- **Sintesis**: SWiM, Harvest Plot, meta-analisis jika ≥3 studi homogen
- **Kepastian bukti**: GRADE
